Code Verdict v0.4.1
Judge the AI’s review, then ship it to GitLab. Run a Copilot review agent on a merge request, decide every finding, and post the ones that matter.
hve-toolsGitLab · Copilot · Code reviewMIT
{{ t.label }}
An AI review is a pile of comments. A review is a decision. Point a Copilot agent — your own, or one from your workspace like HVE Core / PR Review — at a GitLab merge request. Verdict collects its findings as reviewable items with severity, category and confidence. You work through them one at a time, deep-diving with the agent where it matters, and mark each Accepted, Rejected or Skipped. Then Verdict writes the review: inline comments with applyable suggestions for what you accepted, a summary in your words, and nothing at all for what you threw out.

The mark is typographic, not illustrative: square brackets — the punctuation of code — closing around a check. It reads as approval *inside* source, which is the whole product. At 24px the brackets drop away and the check goes solid on brand orange, so the activity bar stays legible. Ship as SVG with the glyph converted to outlines (no font dependency), plus 128px PNG for the marketplace. One-colour variant for docs and the light-theme tile darkens the accent to #b8341d for contrast.
